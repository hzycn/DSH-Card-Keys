为 DSH的选项卡片和权限卡片提供一个 数字键，方向键的快捷操作
默认开启。数字键 1-9 直接选择选项，← → ↑ ↓ 在选项与按钮间移动，回车确认，Esc 关闭提问卡片。数字键同步显示在 DSH 设置 → 通用 → 键盘快捷键 的审批分组中。在输入框里打字时按键保持原样。


Provide number-key and arrow-key shortcuts for DSH's option cards and permission cards.
Once enabled, number keys 1–9 directly select options, ← → ↑ ↓ move between options and buttons, Enter confirms, and Esc closes the question card. The number keys are also displayed in the Approval group under DSH Settings → General → Keyboard Shortcuts. When typing in the input field, key presses behave as usual.
